About the Project

This McCulloch-Pitts NOR Gate Simulator was developed as an educational tool for Deep Learning students.

Technology Stack

Python 3.12 (Flask) HTML5 & CSS3 Bootstrap 5 JavaScript (ES6) SQLite

Future Scope

  • Implement AND, OR, NAND, and XOR Gates
  • Add Perceptron Learning Algorithm
  • Extend to Multi-Layer Perceptron (MLP)
  • Integrate TensorFlow & PyTorch representations

Designed for educational purposes and portfolio showcases.
